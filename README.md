# Vantyx — Paperclip Company

AI-orchestrated web-transformation agency for local home-services businesses (electricians, plumbers, HVAC, roofers, general contractors).

## Import on the droplet

```bash
npx companies.sh add https://github.com/Rfog88/vantyx/tree/master
```

For updates after the first add:

```bash
npx companies.sh add https://github.com/Rfog88/vantyx/tree/master --update
```

## Repo layout

```
vantyx/
  COMPANY.md             # Company manifest (agentcompanies/v1)
  .paperclip.yaml        # Routines (cron-triggered work)
  agents/                # One folder per agent, four files each
    ceo/                 # AGENTS.md (ENTRY), HEARTBEAT.md, SOUL.md, TOOLS.md
    cto/
    cmo/
    ux-designer/
    developer/
    sdr/
  skills/                # Custom SKILL.md files (added to company library, then enabled per-agent in UI)
  shared/                # Cross-agent artifacts (brand, lessons, active clients)
    brand/vantyx.md            # Agency-brand source of truth; feeds the demo prompt
    lovable-demo-prompt.md     # Template prompt prompt-fill sends to Lovable to build a demo
    brand/clients/             # Per-client brand files (dormant under the Lovable pipeline)
    clients/active.md          # Active client engagements
    lessons.md                 # Failure-mode notes appended by any agent
  migrations/            # SQL migrations for the SQLite leads store
```

## Demo build pipeline (Lovable)

Demos are generated by **Lovable** via its MCP server (`https://mcp.lovable.dev`,
OAuth, connected to the demo-gen agent), not the retired `vantyx-web-os`
template. Per lead: `prompt-fill` (fills `shared/lovable-demo-prompt.md`) → Lovable
MCP `create_project(name=<slug>)` → `set_project_visibility` public →
`deploy_project` (publishes `<slug>.lovable.app`) → `lead-update` (stage
`demo_built`, `demo_url=https://<slug>.usevantyx.com`) → `demo-smoke-check`. The
Lovable MCP has no file-export tool, so demos use Lovable hosting; a Cloudflare
Worker (`infra/cloudflare/`) serves them under the branded `<slug>.usevantyx.com`
so prospects never see `lovable.app`. The demo then **waits for Ryan to approve it
in the Paperclip UI** (surfaced by the `morning-demo-review` routine at 7am
Mon–Fri); only on approval does the SDR send outreach. One-time setup: connect the
Lovable MCP via OAuth (Claude Code on the droplet) and deploy the Cloudflare proxy.

## Cost model (important)

Agent execution runs on Ryan's CLI subscriptions (Claude Max, ChatGPT Pro w/ Codex, Gemini AI), NOT on API tokens. Paperclip's Budget tab shows notional USD as a rate-limit signal — actual cost is the flat subscription. Only external service keys (SerpAPI, Vercel, Discord, Resend, Mapbox, etc.) plus **Lovable build credits** (metered on the Lovable plan) are billable per-use.
